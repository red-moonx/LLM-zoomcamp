# Module 03: Orchestration

## Context Engineering

LLM models are only trained up to a certain date. While modern models can also use live web search to fetch real-time information, web search alone is not a guarantee of accuracy because the model will look for info everywhere (and not everywhere is correct).

Therefore, it is essential to provide good context. LLMs perform only as well as the context they receive.
